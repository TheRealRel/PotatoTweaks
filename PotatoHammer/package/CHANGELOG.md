# Changelog

## 1.0.1
- **No more doubles**: a moved piece now shows only on its mod's tab. Before, mods' own build tags kept them in the game's categories too (a mod's beam under Walls), and BoatAdditions, SimpleElevators and TarCollector each listed all three mods' pieces, because those mods share a piece library that gives their tags the same number ("CollectorSeries" was TarCollector's).
- Tab names now have spaces: "Boat Additions", "Simple Elevators", "Tar Collector". Tabs you renamed keep your name.
- Removed the 90-piece split: the game's build menu scrolls, so every mod gets one tab.

## 1.0.0
- First release: each mod's hammer pieces move to a tab named after the mod; the game's own pieces stay where they are.
